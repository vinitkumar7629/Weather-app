# Weather App

A weather app that fetches real-time data using the OpenWeatherMap API. Search any city to see current temperature, humidity, wind speed, and "feels like" temperature.

## Live Demo
https://vinitkumar7629.github.io/Weather-app/

## Built With
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## Features
- Real-time weather search by city name
- Error handling for invalid city names
- Responsive design
- Loading state while fetching data
